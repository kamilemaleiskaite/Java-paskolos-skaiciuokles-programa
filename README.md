# Java Loan Calculator

## Overview

The Java Loan Calculator is a Java application developed to perform loan-related calculations. The project focuses on applying programming logic to financial calculations and presenting the resulting information to the user.

## Technologies

- Java
- Maven

## Features

- Loan-related calculations based on user-provided information.
- Calculation of financial results.
- Generation of a report file.

## Getting Started

### Prerequisites

- Java JDK compatible with the project configuration.
- Maven (optional, as the repository includes a Maven Wrapper).

### Running the Project

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. Build the project using the Maven Wrapper:

   ```bash
   ./mvnw clean package
   ```

   On Windows, use `mvnw.cmd clean package`.

4. Open the project in IntelliJ IDEA and run the main application class, or follow the execution configuration defined in the project.

## Learning Outcomes

This project provided experience with Java application development, financial calculations, structured project configuration, and generating calculation reports.
